This assignment has two C++ programs that show the use of loops and conditional statements.

Program 1 prompts the user to enter a menu choice and continues asking until a valid option (1, 2, or 3) is entered.
Program 2 prompts the user for a number and displays its multiplication table from 1 through 10.

To run either program, compile the corresponding source file with a C++ compiler and execute the resulting program.
