This assignment has three C++ programs that show the use of arrays, functions, loops, and searching techniques.

Program 1 prints an array in both forward and reverse order and counts how many values are greater than a user-specified limit.
Program 2 allows the user to enter five scores and then calculates and displays the sum, average, highest score, and lowest score.
Program 3 searches an array for a user-specified value, reports the index of its first occurrence, and counts how many times it appears.

To run any program, compile the corresponding source file with a C++ compiler and execute the resulting program.
